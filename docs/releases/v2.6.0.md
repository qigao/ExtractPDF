# QuantaPDF 2.6.0

QuantaPDF 2.6.0 adds explicit immutable PDF security rewrites while preserving
ABI/SOVERSION 2.

## Added

- `quantapdf_encrypt_pdf()` for R6/AES-256 output from unencrypted input.
- `quantapdf_decrypt_pdf()` for deterministic plaintext output from an
  authenticated encrypted document.
- `quantapdf_reencrypt_pdf()` for replacing passwords, permissions, metadata
  policy, keys, salts, IVs, and update identifiers.
- A size-tagged `quantapdf_encryption_options` record with exact semantic
  permission flags and an explicit metadata-encryption choice.
- A private Windows/Linux/macOS OS-CSPRNG adapter installed into qpdf once for
  process lifetime, with thread-local configuration/write attribution and no
  transient global-provider swap.
- Exact shared-library export isolation for qpdf, PDFium, and other private
  dependency symbols.

## Contract

- Output encryption is PDF 1.7 extension level 8, Standard Security Handler
  `V=5`, `R=6`, with AESV3 string, stream, and embedded-file crypt filters.
- V1 passwords are printable ASCII, at most 127 bytes. Empty user passwords
  are allowed; owner passwords must be nonempty and distinct.
- Permissions are advisory. Accessibility extraction remains enabled as
  required by R6 and is not exposed as a false restriction switch.
- Encryption and re-encryption are intentionally non-deterministic;
  authenticated decryption is deterministic for identical input.
- Signed, malformed, wrong-state, and unauthenticated input fails closed with
  NULL output. Successful output remains valid after its source closes.
- Static consumers that replace qpdf's process-global provider after library
  initialization receive `QUANTAPDF_ERROR_UNSUPPORTED` from encryption rather
  than having their pointer temporarily overridden.
- No existing transform changes document encryption implicitly.

## Compatibility and dependencies

- Feature version: 2.6.0.
- ABI/SOVERSION: 2.
- Public exports: 98, exactly three more than 2.5.0.
- PDFium remains pinned to 154.0.8021.0 and qpdf to 12.4.0.
- No dependency was added; no MuPDF or AGPL code is used.

## Verification

The dedicated `quantapdf.pdf_security_rewrite` test covers ABI layout, input
validation, permissions, passwords, metadata encryption, authentication,
production randomness, file identifiers, entropy faults/context cleanup,
static-provider conflict and concurrency, source/output ownership, legacy
encryption, current and incremental signature rejection, and non-vacuous
public text/render/image/link/annotation/form/outline/metadata semantic
preservation.

Fresh Windows Release and MSVC AddressSanitizer clean builds each completed
with 36/36 CTests passing, including the exact 98-symbol DLL export check and
no sanitizer diagnostic. The exact final code head repeated both complete test
suites successfully. Release installation succeeded; a standalone C11 consumer
compiled only against the installed header/import library, resolved all three
new functions, and ran with version 2.6.0/ABI 2. The installed DLL independently
passed the repository's exact 98-export checker. A separate static MSVC
AddressSanitizer build passed the public audit and rewrite security tests.

Independent exact-head security review approved commit `3806798` with no
Critical, Important, or Minor findings remaining.
