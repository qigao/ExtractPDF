# QuantaPDF 2.5.0

QuantaPDF 2.5.0 adds a stable-ABI Composer for generating straightforward PDF
documents from formatted text and raster images.

## Added

- Opaque `quantapdf_composer` lifecycle under the existing ABI v2.
- Versioned page, text, image, and capacity option records.
- Deterministic, non-consuming finish into independent `quantapdf_output`
  snapshots.
- Top-left point-space page creation and base-14 text layout with color,
  line spacing, wrapping, and left/center/right alignment.
- Reusable JPEG and PNG image resources with contain, cover, and stretch fit.
- RGB/RGBA PNG decoding with CRC validation and PDF soft-mask alpha.
- Explicit page, operation, and owned-resource capacity limits.

## Compatibility

- `QUANTAPDF_ABI_VERSION` remains 2; the new functions are additive exports.
- The feature version is now 2.5.0 and the shared-library SOVERSION remains 2.
- Composer text V1 is limited to WinAnsi characters supported by the base-14
  Helvetica, Times, and Courier variants. Embedded fonts and complex shaping
  will require a future additive API.

## Dependencies

No dependency was added. qpdf writes the generated document, zlib handles PNG
scanlines, and PDFium continues to provide inspection/render verification.
No MuPDF or AGPL code is used.
